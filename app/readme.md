#  Doodle Draw

A simple and creative Android drawing application built with **Kotlin** and **Android Studio**.

Doodle Draw provides a lightweight canvas where users can freely draw, experiment with colors, and create their own digital sketches.

---

##  Project Overview

**Doodle Draw** is an Android-based drawing application designed with a simple and user-friendly interface.

The project is being developed with the goal of creating a clean drawing experience while maintaining a modular and maintainable Android project structure.

### Current Project Focus

- 🎨 Drawing canvas
- 🖌️ Brush interaction
- 🌈 Color selection
- ↩️ Undo functionality
- 💾 Drawing-related UI
- 📱 Android-native interface

---

## ✨ Features

###  Drawing Canvas
Draw freely on the canvas using touch gestures.
###  Brush Controls
Customize the drawing experience through brush-related controls.
###  Color Selection
Choose different colors for drawing and experimenting with your artwork.
###  Undo
Undo previous drawing actions when needed.
###  Save & Gallery
The project includes UI components for drawing-related save and gallery functionality.
